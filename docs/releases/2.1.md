# Sloth OS 2.1

*November 2026*

**Download:** (the links and the checksum come with the ISO)
[Installation guide](https://sloth-os-linux.github.io/download.html)

Already running Sloth OS? You get 2.1 as a normal, small update, no reinstall needed. After it, a notification
tells you what is new (Sloth Center → Updates shows it too).

## Safer changes

- **Restore points:** before a bigger change (a new taskbar layout, switching the graphics driver, Advanced settings
  such as driver options, loading a settings file) Sloth OS keeps the system as it was. Sloth Center → Updates →
  Restore points takes it back, the way Windows' System Restore does. (System updates keep the previous version
  anyway, as before.)
- **Every update in one place:** the Updates page now lists the Windows programs' updates too, next to the system's.
  Apps from the store still update themselves.

## Signing in

- **The PIN in the security chip:** on a computer with a TPM, the PIN is kept in the chip, which also limits the wrong
  tries. Nothing on the disk can be used to guess it. Without a TPM it stays a protected hash, readable only by the
  system.
- **The PIN opens your saved passwords:** give your account password once when you set the PIN, and signing in with
  the PIN opens the password store (KWallet) too, like Windows Hello. Wi-Fi, network folders and browsers no longer
  ask again. If you set a PIN before, a notification tells you once how to turn this on.
- **The PIN works everywhere:** on the sign-in screen, the lock screen and the administrator password dialog.
- **A child who can't sign in** (outside the allowed hours, or the daily time used up) sees why on the sign-in screen.

## Games and drivers

- **Game fixes from other players for Steam games too:** when a Steam game needed a setting to run, Sloth OS can share
  it (its own switch, off unless you turn it on), and you get what worked for others, with how many players it helped
  and when. A fix that stopped working can be reported as outdated.
- **Sharing made clear:** one question in Sloth Center with two switches, Windows programs and Steam games.
- **Driver options** in Sloth Center → Advanced settings: a known fix with one button when this computer needs it
  (for now: a Realtek Wi-Fi card that keeps dropping), an option a guide recommends, or a driver turned off. They
  take effect after a restart, with a restore point first. Until now this needed a terminal.

## Fixes

- The PIN on the sign-in screen and in the password dialog (it worked on the lock screen only).
- The sign-in screen's rebuild never removes anything that came with the system.
- A Hungarian screen time text that read wrong for some times.
- Every new text is available in all 50 languages.

## Requirements

A 64-bit PC (UEFI or the older BIOS mode), 4 GB of memory (16 GB for games), 64 GB of disk space, and a USB stick
of 8 GB or more. Feedback: Sloth Center → Help and feedback → Feedback.
