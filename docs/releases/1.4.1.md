# Sloth OS 1.4.1

*November 4, 2026*

**Download:** the 1.4.1 installer ISO is on its way; the links and the checksum follow here as soon as it is up.
[Installation guide](https://sloth-os-linux.github.io/download.html)

Already running Sloth OS? You get 1.4.1 as a normal, small update, no reinstall needed.

## Older NVIDIA graphics cards

On NVIDIA cards older than the GeForce RTX 20 series (for example a GeForce GTS 450 or a GTX 1060), which run on the
open driver:

- **No more black screen or flickering after signing in.** The newest KDE Plasma (6.8) has a bug with the open
  driver's older way of driving the screen: the picture went black and only came back while the mouse moved. On
  these cards the driver now uses its newer way (atomic mode setting), which the Linux kernel itself is about to
  turn on for them, and the bug does not happen there. Other computers are not affected.
- **Brave, Chrome, Spotify, Discord and other Chromium-based apps no longer crash** on these cards: they draw
  without the graphics card, which these old cards could not speed up much anyway.

## Signing in automatically

- **On an encrypted disk, the password store opens by itself.** With automatic sign-in, the password you type at
  startup to unlock the disk now also opens the store of saved passwords (Wi-Fi, network folders), so it no longer
  asks again.
- **Without disk encryption it asks once after each start,** as before: the saved passwords stay encrypted on the
  disk. The automatic sign-in switch in the welcome wizard and in Sloth Center → Account and security now says
  this.

## Installing next to Windows

- **"We couldn't check the Windows drive" is fixed.** The installer's disk survey stopped when the desktop of the
  installer opened Windows' boot partition at the same moment. It now waits and goes on.
- **A Windows drive encrypted with BitLocker** (Windows 11 turns it on by itself on many computers) is now named as
  such, with what to do, instead of "couldn't check".

Every new text is available in all 50 languages.

## Known rough edges

- **Installing next to Windows can keep asking for a disk check on some computers,** even after shutting Windows
  down with Shift + Shut down. The sure way around it: in Windows, open Disk Management (right-click the Start
  button), right-click drive C: → Shrink Volume, and free at least 64 GB. The installer then puts Sloth OS into that
  free space and does not touch the Windows partition at all, so no disk check is needed.

## Requirements

A 64-bit PC that starts in UEFI mode, 4 GB of memory (16 GB for games), 64 GB of disk space, and a USB stick of
8 GB or more. Feedback: Sloth Center → Feedback.
