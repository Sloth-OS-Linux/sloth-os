# Sloth OS 1.2.1

*October 29, 2026*

**Download:** [sloth-os-1.2.1-x86_64.iso](https://sourceforge.net/projects/sloth-os/files/1.2.1/sloth-os-1.2.1-x86_64.iso/download)
(the SHA-256 checksum is in the `.sha256` file next to it) · [Installation guide](https://sloth-os-linux.github.io/download.html)

Already running Sloth OS? You get 1.2.1 as a normal, small update, no reinstall needed.

## Roblox

- **Sober** in Sloth Welcome's Games: Roblox games, through a community app made for Linux (Roblox blocks its
  Windows version on Linux).
- **Roblox Studio** in Sloth Welcome's Games: the official installer, downloaded and installed after the wizard
  like the other Windows launchers. Logging in works.
- **"Will it run?"** answers Roblox with Sober, instead of only saying that it is blocked.

## Windows programs

- **Logging in through the browser works:** many Windows programs open the browser for the login and get the result
  back through a link of their own (Roblox Studio, launchers). Sloth OS now passes these links to the program.
- The Microsoft Edge WebView2 component that some installers bring along is no longer mistaken for the installed
  program, and it gets no Start menu entry.

Every new text is available in all 50 languages.

## Known rough edges

- Roblox Studio's maximize button does nothing; drag the window bigger instead (it opens large).

## Requirements

A 64-bit PC that starts in UEFI mode, 4 GB of memory (16 GB for games), 64 GB of disk space, and a USB stick of
8 GB or more. Feedback: Sloth Center → Feedback.
