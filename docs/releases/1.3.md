# Sloth OS 1.3

*November 2, 2026*

**Download:** the 1.3 installer ISO follows in the next few days. Until then, install with the
[1.2.1 ISO](https://sourceforge.net/projects/sloth-os/files/1.2.1/sloth-os-1.2.1-x86_64.iso/download): it updates

Already running Sloth OS? You get 1.3 as a normal, small update, no reinstall needed.

## Folder sharing on the home network

- **Share a folder with the other computers at home:** Sloth Center → Disks → Share a folder, or Dolphin → right
  click → Properties → Share. With a password or, if you choose so, without one; read-only or with changes allowed.
  Folders on another disk can be shared too.
- **The computer shows up in Windows' Network window** (and in the Network view of other Linux computers), under
  its name.
- **Safe by default:** turning sharing on asks for the administrator password, like Windows. Only the local network
  can connect, never the internet, and the server reads only the folders you share. When nothing is shared any more,
  sharing switches itself off.
- **At work:** on a computer joined to a work domain (Sloth Center → Accounts), a shared folder can be opened to
  Active Directory groups, read-only or with changes allowed.

## Safer folder sharing (SMB)

- **Home, private and public networks, as in Windows.** At home the computer shows up on the network and your shared
  folders open. On a private network (a workplace) they open, but the computer does not announce itself. On a public
  network (a café, a hotel) the computer stays hidden and nothing opens.
- **A new network is asked about once** (a notification with three buttons, no password). Over a cable, each router
  counts as its own network, so the cable at home and the one in a hotel are told apart. The networks you saved
  before count as home networks; a notification tells you once, and Sloth Center → Disks → Networks can change them.
- **Sharing on a public network** is possible too, after a clear warning; it is remembered for that network, and the
  warning says where to change it.
- **Every share needs the administrator password**, also one made in Dolphin: until you allow it, the folder is not
  shared (a notification asks, and Sloth Center → Disks lists it as waiting). Allowing sharing on a public network
  needs it too. Both ask even if you turned the other password prompts off (Sloth Center → Account and security
  says so).
- **A switch for folder sharing** in Sloth Center → Disks: off, the sharing service stops and stays stopped.
- **Fixes:** stopping a share in Dolphin now closes it everywhere (before, the computer could stay open and visible
  on the network); the computer is no longer announced while nothing is shared; a folder shared without a password
  opens from your home folder too, and the guest gets into that folder only.

## Typing and looks

- **Chinese, Japanese and Korean typing works** (fcitx5 with its input engines, switched on for these languages).
- **Your own highlight color:** the color scheme's own, 8 suggestions or any color, in Sloth Welcome and Sloth Center
  → Appearance. It can color the window title bars too.
- The boot logo stays in the middle with two screens of different sizes.

## Smaller changes

- **Sloth Center is among the Start menu favorites** (with Dolphin and Discover) for new accounts.
- **The Games page lists only games** and stays up to date; Programs → More → "It's a game" lets you say it either
  way.
- Sloth Welcome and the Windows program installer say up front that not every Windows program runs.
- The restart button shows that it is restarting.
- Feedback reports are private now.
- Installer and PIN: Tab goes from the password to the second password field.

Every new text is available in all 50 languages.

## Requirements

A 64-bit PC that starts in UEFI mode, 4 GB of memory (16 GB for games), 64 GB of disk space, and a USB stick of
8 GB or more. Feedback: Sloth Center → Feedback.
