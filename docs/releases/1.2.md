Already running Sloth OS? You get 1.2 as a normal update, no reinstall needed.

## Much smaller updates

Until now, even a small change meant a 2–4 GB system update. The system image is now built from content-based
parts, so an update downloads only the parts that changed: on a real machine, a typical update came down at about
**300 MB**. The installer ISO is smaller too: 5.2 GB instead of 7.0 GB.

> **Updating from 1.1 or earlier:** the first update to 1.2 downloads the whole system once (about 4.5 GB),
> because every part has a new shape. Leave the computer on and connected until it is ready; after that, updates
> are small.

## New in Sloth Center

- **Help:** answers to the most common problems (Sloth OS doesn't start, an update caused trouble, no internet, a
  lost file, a game or Windows program that doesn't start, no sound, the screen looks wrong, installing again),
  offline and in every language, each with a button to the page that fixes it.
- **"Will it run?"** on the Games page: search about 20 000 games and see how well each one runs on Linux,
  from other players' reports, with the anti-cheat and the source of every answer. When a game's makers block
  Linux, it says so plainly, and whom to ask.
- **Move a Steam game to another drive** without downloading it again: the game, its saves and settings, and Steam's
  library list move together.
- **Network folders:** a NAS or another computer's shared folder in the file manager's side panel, found on the
  network by itself or typed the way Windows writes it (`\\NAS\Photos`). It stays after a restart, and if a NAS
  shares nothing yet, it tells you which setting to turn on.
- **Quiet hours:** no restart reminders in the part of the day you choose (to the minute, over midnight too); they
  come back when the quiet hours end.
- **Choose when updates download:** pick the hour the automatic update runs.
- **Display and sound profiles:** save your setup (monitors, speakers or headphones, microphone) as "Desk", "TV" or
  "Headset", and switch with one click.
- **Save your Sloth OS settings to a file** and load them on a new install or another computer: the look, the
  profiles, the quiet hours, and your apps, which Sloth Welcome installs again.
- **Clean up** first shows what it would delete and how much space each item frees, and deletes only what you
  tick.

## Installer and Windows programs

- **The installer checks the computer on its first page:** a computer started in the old BIOS mode is told how to
  start in UEFI mode before anything is touched; little memory or a laptop on battery get a warning (it updates when
  you plug in the charger).
- During the last steps of installing, the progress text says what is happening instead of standing still at 80%.
- **Windows programs built on Windows' newest interface** (WinUI 3 / .NET MAUI), which do not run on Linux yet, are
  recognized and explained, instead of trying every setting in vain.
- **From the USB stick (live mode),** Windows programs start sooner and use less memory: the bundled runtime is no
  longer copied first.

Every new text is available in all 50 languages.

## Requirements

A 64-bit PC that starts in UEFI mode, 4 GB of memory (16 GB for games), 64 GB of disk space, and a USB stick of
8 GB or more. Feedback: Sloth Center → Feedback.
